RideHero v7.0 - Mode Choice Experience

This build introduces the major app direction discussed:
- Coaster intro runs first.
- Pull-away reveals a split mode choice screen.
- User can tap or swipe:
  - Quick Route
  - Maximize My Day
- Same app layout remains after the choice.
- Selected mode changes the app's logic and visual feel.
- Quick mode prioritizes fast next-best-route guidance.
- Maximize mode prioritizes strategic full-day optimization.
- Adds a visible mode pill to change mode later.
- Adds RideHero Advisor card for the selected guidance style.

Preserved:
- v6.9 storyboard intro behavior
- Disney franchise hub
- single-row Plan Tools
- park isolation fixes
- routing cleanup
- Disney map assets
