RideHero v7.6 - Mode Spinner Widget + Contextual UI

This build adds the floating mode widget:
- Bottom-right floating circular mode widget.
- Uses circular arrow styling inspired by the supplied sketch.
- Shows the current mode in the middle: Quick or Plan.
- Slowly spins.
- Defaults to 20% opacity when idle.
- Becomes fully visible on press/hover/focus.
- Pressing it toggles Quick Route / Plan My Day.
- Quick Route hides planning-heavy UI such as Plan Tools and starter/suggested plan sections.
- Plan mode shows those sections again.
