RideHero v8.3 - Hide Context Until Park Selection

This build removes the weather/crowd context cards from the initial destination chooser:
- Weather and Crowd Level cards are hidden before a park is selected.
- The cards remain hidden on the destination selection page.
- Park context visibility is now controlled after a park selection.
- Preserves v8.2 destination flow, Quick mode route jump, Plan mode planning page, v8.1 coaster train physics, hidden pull effect, mode spinner behavior, Disney maps, routing, and UI improvements.
