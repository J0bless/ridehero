RideHero v8.2 - Dedicated Destination Flow

This build changes the app flow:
- Destinations is now its own page/flow.
- The destination page focuses only on franchise + park selection.
- Planning-heavy content is removed from the destination page.
- In Quick mode, after choosing a destination and park, RideHero immediately opens the Route tab and builds a quick starter route.
- In Plan/My Day mode, after choosing a destination and park, RideHero opens a Plan page with Plan Tools, suggested morning sweep, and full-day hours.
- Bottom nav label changed from Home to Destinations.
- Preserves v8.1 coaster animation polish, hidden pull effect, mode spinner behavior, full-screen mode choice, Disney maps, routing, and UI improvements.
