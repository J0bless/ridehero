RideHero v7.2 - Full-Screen Mode Choice

This build fixes the first v7.0/v7.1 mode-choice issues:
- Swipe works across the entire mode-choice screen.
- Buttons no longer swallow the swipe gesture.
- Adds pointer and touch fallback support.
- Quick Route and Maximize My Day now fill the whole page.
- Full-screen split uses the squiggly divider as the main visual separation.
- Tap selection still works.
- Mode pill and Advisor card remain after selection.
